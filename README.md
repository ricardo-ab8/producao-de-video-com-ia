# Pensar como um Diretor · Produção de Vídeo com IA

Página do curso **Produção de Vídeo com IA**, do Ricardo Studio em parceria com a ORAYON.

## Conteúdo da pasta

- `index.html`: a página inteira (estilos, fontes e animações já estão dentro dela)
- `m/`: vídeos e imagens usados na página
- `.nojekyll`: avisa o GitHub Pages para publicar os arquivos como estão

## Como publicar no GitHub Pages

1. Em github.com, clique em **New repository**. Dê um nome (ex.: `curso-video-ia`), deixe **Public** e crie.
2. Na página do repositório, clique em **uploading an existing file** e arraste **todo o conteúdo desta pasta** (o `index.html`, a pasta `m` e o `.nojekyll`). Clique em **Commit changes**.
3. Vá em **Settings → Pages**. Em *Source*, escolha **Deploy from a branch**, branch **main**, pasta **/ (root)**, e salve.
4. Em 1 ou 2 minutos o link aparece no topo dessa tela: `https://SEU-USUARIO.github.io/curso-video-ia/`.

## Para atualizar

Envie de novo o `index.html` (e qualquer arquivo novo da pasta `m`) pelo mesmo botão **Add file → Upload files**. O link continua o mesmo.
